# Opciones de Proyecto — Elige una

Cada app debe tener un menú con mínimo 4 opciones + Salir.

1. **Sistema de inventario** — agregar producto, ver stock, buscar producto, eliminar producto, salir

2. **Agenda de contactos** — agregar contacto, buscar contacto, ver todos, eliminar contacto, salir

3. **Registro de asistencia** — marcar asistencia, ver lista de asistentes, ver ausentes, buscar persona, salir

4. **Conversor de unidades** — convertir temperatura, convertir moneda, convertir distancia, ver historial, salir

5. **Sistema de reservas** — agendar cita, ver citas del día, cancelar cita, buscar disponibilidad, salir

6. **Lista de tareas (to-do)** — agregar tarea, marcar completada, ver pendientes, ver completadas, salir

7. **Gestor de biblioteca personal** — agregar libro, buscar libro, marcar como leído, ver pendientes de leer, salir

8. **Calculadora de propinas y división de cuenta** — calcular propina, dividir cuenta entre personas, ver historial, cambiar porcentaje, salir

9. **Registro de entrenamientos (gym)** — agregar ejercicio del día, ver historial semanal, calcular progreso, buscar ejercicio, salir

10. **Sistema de votación simple** — registrar voto, ver resultados, ver participantes, reiniciar votación, salir
